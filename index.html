你好！我是江心悠，广州航海学院 / 广州交通大学（筹）车辆工程专业本科生（2024–2028），专业综测排名 1 / 34。目前在大湾区大学担任访问学生，开展轮足机器人零样本物体导航研究。

我曾担任 RoboMaster ICBK 破冰船战队导航组组长，从仿真搭建到实车部署，开发机器人自主导航、路径规划与感知系统；同时参与智能氢能无人船导航控制研究，关注算法在真实环境中的稳定运行。

研究兴趣：具身智能、机器人自主导航、多传感器融合与机器人控制。

实践方向：从感知到行动，从仿真到现实，探索机器人在真实环境中的自主运行。

06 个项目

轮足机器人的零样本多楼层物体导航

Zero-shot Multi-floor Object Navigation

大湾区大学 · 访问学生

面向 TITA 轮足机器人，研究不依赖平台特定训练策略的物体目标导航。结合语义地图、多楼层规划与视觉语言模型，让机器人在复杂空间中寻找目标并应对动态行人。

静态仿真：SR 63% · SPL 28.5%

ObjectNavVLM语义地图动态避障
项目详情

构建物体、语义与可通行三层地图；由启发式多楼层规划器负责单层探索与跨楼层转换，多视点 VLM 验证模块负责目标确认，动态行人避障流水线负责前瞻性避让。跨地形能力仍在研究中，下一阶段将探索利用强化学习实现上下楼时的抬腿与收腿动作。

RoboMaster 全向哨兵自主导航

Omnidirectional Sentry Navigation · Sim2Real

ICBK 破冰船战队 · 导航组组长

基于 ROS2 Humble 与 Nav2，构建从激光雷达感知、定位建图、路径规划到实车底盘控制的完整导航系统，支持战术巡逻、动态目标追击与实时避障。

Gazebo 仿真 → 真实机器人部署

ROS2Nav2Livox Mid360Fast-LIO / Point-LIO
项目详情

融合 Livox Mid360、IMU、Fast-LIO / Point-LIO、点云地面分割与裁判系统，形成感知、决策、规划、执行的 Sim2Real 闭环。由组员成长为导航组组长，负责自主导航与路径规划代码开发、系统联调及技术文档编写。

智能氢能无人船导航控制

Navigation & Control for Hydrogen-powered USV

国家级大创项目 · 导航算法开发

针对氢燃料电池系统 1–3 秒输入时滞，设计基于辅助系统的路径跟踪控制方案。融合 GPS、毫米波雷达与视觉传感器，开展水域自主避障与路径规划验证。

导航算法三次迭代 · 响应时间缩短 30%

SLAM多传感器融合路径跟踪自适应模糊控制
项目详情

导航算法由 PID 迭代至自适应模糊控制，再整合多传感器融合避障。完成真实水域数据采集与模型验证。相关《水面深度测绘氢能智能无人船关键技术研究》获国家级大创立项，智能氢能无人船项目获大学生国际创新创业大赛省级铜奖。
